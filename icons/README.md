# PWA Icons

This directory should contain the following PWA icons:

- `icon-192x192.png` - 192x192 px app icon
- `icon-512x512.png` - 512x512 px app icon

These icons will be created in Epic 1, Story #9.

For now, the app will work without these icons, but they are required for PWA installation.

Design guidelines:
- Hupyy branding (shield or verification symbol)
- Primary color: #007AFF (macOS blue)
- Background: #F5F5F7 or transparent
- Simple, recognizable design
